# MCP Debugging Guide

A comprehensive guide to debugging [Model Context Protocol (MCP)](https://modelcontextprotocol.io)
integrations — covering the tools, logging approaches, common issues, and
workflows for developing MCP servers and integrating them with clients.

## Contents

- [Debugging Guide](docs/debugging.md) — the full guide, covering:
  - Debugging tools overview (MCP Inspector, server logging, client dev tools)
  - Implementing server-side logging (stdio and Streamable HTTP transports)
  - Common issues (working directory, environment variables, startup, connection)
  - Debugging in Claude Desktop (server status, logs, Chrome DevTools)
  - Debugging workflow and best practices
